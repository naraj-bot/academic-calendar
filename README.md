# ระบบปฏิทินการศึกษาและแผนปฏิบัติงาน

ปฏิทินการศึกษาสำหรับโรงเรียน มีตารางวันเรียน Day 1–200 ปฏิทินรายภาคเรียน และแผนปฏิบัติงาน 4 ฝ่าย
ใช้ **Vercel** เผยแพร่หน้าเว็บ และ **Firebase** (Authentication + Firestore) เก็บข้อมูลและบัญชีผู้ใช้
ใช้แพ็กเกจฟรีได้ทั้งสองบริการ

**พัฒนาโดย ครูซอสสอนสังคม 2569**

---

## ความสามารถ

- หน้าเข้าสู่ระบบด้วย **ชื่อผู้ใช้ + รหัสผ่าน** แสดงปีการศึกษา ภาคเรียนปัจจุบัน และแถบเส้นเวลาทั้งปี
- ภาพรวม: วันนี้เป็นวันเรียนที่เท่าไร ครบเกณฑ์ 200 วันหรือยัง และกำหนดการ 30 วันข้างหน้า
- ตารางวันเรียน Day 1–200 พอดีจอ คำนวณวันเรียนสะสมอัตโนมัติ นับวันเรียนชดเชยด้วย
- ปฏิทินภาคเรียนที่ 1 / 2 ภาคปัจจุบันขึ้นในเมนูเอง
- แผนปฏิบัติงาน 4 ฝ่าย ติ๊กเลือกฝ่ายที่จะแสดงได้ และเพิ่มหลายกิจกรรมหลายฝ่ายได้ในครั้งเดียว
- เก็บข้อมูลแยกตามปีการศึกษา ดูย้อนหลังได้ทุกปี และคัดลอกแผนงานไปปีใหม่ได้
- พรีวิวก่อนพิมพ์ สั่งพิมพ์ตรงได้ หรือดาวน์โหลดเป็น **PDF** หรือ **รูป PNG**
- บทบาท 3 ระดับ: แอดมินหลัก / แอดมินโรงเรียน / ครู-บุคลากร หนึ่งคนมีได้หลายบทบาทและสลับบทบาทได้
- เพิ่มผู้ใช้ทีละหลายคน วางรายชื่อจาก Excel ได้ สุ่มรหัสผ่านได้ และดาวน์โหลดรายชื่อเป็นไฟล์ Excel
- หน้า **คู่มือการใช้งาน** ในระบบ แสดงเนื้อหาตามบทบาทของผู้ใช้
- ถังขยะ (กู้คืนได้) และประวัติการแก้ไขทุกครั้ง

## โครงสร้างไฟล์

```
index.html              หน้าเว็บหลัก
css/style.css           หน้าตาทั้งระบบ (โทนแดง-ทอง ฟอนต์ Anuphan)
js/app.js               การทำงานทั้งหมด
js/firebase-config.js   ← ต้องแก้: ค่าเชื่อมต่อ Firebase ของโรงเรียน
firestore.rules         กฎความปลอดภัยของฐานข้อมูล
firebase.json           ใช้เมื่อ deploy กฎผ่าน Firebase CLI (ไม่บังคับ)
vercel.json             การตั้งค่า Vercel
manifest.webmanifest    ไอคอนเมื่อเพิ่มลงหน้าจอมือถือ
assets/                 โลโก้ และ favicon
```

## ขั้นตอนติดตั้ง

### 1. สร้างโปรเจกต์ Firebase

1. เข้า <https://console.firebase.google.com> แล้วกด **Create a project** ตั้งชื่อ เช่น `school-calendar`
   - Google Analytics ปิดได้
2. ในหน้าโปรเจกต์ กดไอคอน **`</>`** (Web) เพื่อเพิ่มเว็บแอป ตั้งชื่อ เช่น `calendar-web`
   - ไม่ต้องติ๊ก Firebase Hosting
3. คัดลอกค่า `firebaseConfig` ที่ขึ้นมา แล้ววางแทนในไฟล์ **`js/firebase-config.js`**

### 2. เปิดระบบเข้าสู่ระบบ (Authentication)

1. เมนูซ้าย **Build → Authentication → Get started**
2. แท็บ **Sign-in method** → เลือก **Email/Password** → เปิด **Enable** (เปิดเฉพาะช่องแรก) → **Save**

### 3. สร้างฐานข้อมูล (Firestore)

1. เมนูซ้าย **Build → Firestore Database → Create database**
2. Location เลือก **asia-southeast1 (Singapore)** → เลือก **Start in production mode**
3. แท็บ **Rules** → ลบข้อความเดิม แล้ววางเนื้อหาทั้งหมดจากไฟล์ **`firestore.rules`** → กด **Publish**

### 4. ขึ้น GitHub และ Deploy บน Vercel

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
   (หรือใช้คำสั่ง `git init` → `git add .` → `git commit -m "first"` → `git push`)
2. เข้า <https://vercel.com> → **Add New → Project** → เลือก repository นี้
3. Framework Preset เลือก **Other** แล้วปล่อยค่าอื่นว่างทั้งหมด → **Deploy**
4. จะได้ลิงก์ เช่น `https://school-calendar.vercel.app`

### 5. อนุญาตโดเมน Vercel ใน Firebase

**Authentication → Settings → Authorized domains → Add domain** → ใส่ `school-calendar.vercel.app`
(ใส่โดเมนจริงของคุณ ไม่ต้องมี https://)

### 6. ตั้งค่าระบบครั้งแรก

1. เปิดลิงก์เว็บ ระบบจะแสดงหน้า **"ตั้งค่าระบบครั้งแรก"**
2. กรอกชื่อโรงเรียน ชื่อแอดมินหลัก ชื่อผู้ใช้ และรหัสผ่าน
3. ติ๊ก "ใส่วันหยุดราชการปี 2569 และแผนงานตัวอย่าง" ไว้ได้ ระบบจะใส่ข้อมูลตั้งต้นให้
4. กด **สร้างบัญชีและเริ่มใช้งาน**

หน้าตั้งค่าครั้งแรกจะขึ้นเพียงครั้งเดียว หลังจากนั้นทุกคนจะเห็นหน้าเข้าสู่ระบบ

### 7. เพิ่มครูและบุคลากร

เมนู **ผู้ใช้งานและประวัติ → เพิ่มผู้ใช้ (ได้หลายคน)**
- ติ๊กบทบาท แล้วกรอกหรือวางรายชื่อจาก Excel 3 คอลัมน์ (ชื่อ-นามสกุล · ชื่อผู้ใช้ · รหัสผ่าน)
- กดบันทึก แล้วดาวน์โหลดรายชื่อพร้อมรหัสผ่านเก็บไว้แจกครู
- แจ้งชื่อผู้ใช้และรหัสผ่านให้ครู แล้วให้ครูเปลี่ยนรหัสผ่านเอง โดยกดที่ชื่อมุมขวาบน → **เปลี่ยนรหัสผ่าน**

## บทบาทผู้ใช้

| บทบาท | ทำอะไรได้ |
|---|---|
| **แอดมินหลัก** | ทุกอย่าง รวมถึงเพิ่ม/ปิด/ลบผู้ใช้ ตั้งชื่อระบบ เปิดปีการศึกษาใหม่ ลบถาวร และล้างข้อมูลทั้งปี |
| **แอดมินโรงเรียน** | เพิ่ม/แก้ไขวันหยุดและแผนงาน แก้ข้อมูลโรงเรียนและวันเปิด-ปิดภาค กู้คืนจากถังขยะ |
| **ครู/บุคลากร** | ดูปฏิทินทุกมุมมองและทุกปี และพิมพ์เอกสาร |

สิทธิ์ทั้งหมดบังคับด้วย Firestore Rules ที่ฝั่งเซิร์ฟเวอร์ ไม่ได้แค่ซ่อนปุ่มในหน้าเว็บ

## คำถามที่พบบ่อย

**ครูลืมรหัสผ่าน**
แอดมินหลักตั้งรหัสผ่านใหม่จากหน้าเว็บไม่ได้ ให้ทำดังนี้:
1. ลบผู้ใช้คนนั้นในหน้า "ผู้ใช้งานและประวัติ"
2. ลบบัญชีเดิมใน Firebase Console → Authentication → Users
3. เพิ่มผู้ใช้ใหม่ด้วยชื่อผู้ใช้เดิม

**เปลี่ยนโลโก้**
เมนู ตั้งค่า → โลโก้ / ไอคอนระบบ → อัปโหลดรูป
ถ้าอยากเปลี่ยน favicon และไอคอนมือถือด้วย ให้แทนไฟล์ใน `assets/` แล้ว push ขึ้น Git ใหม่

**ขึ้นปีการศึกษาใหม่**
แอดมินหลักไปที่ ตั้งค่า → เปิดปีการศึกษาใหม่
- เลือกได้ว่าจะคัดลอกแผนงานจากปีก่อนหรือไม่
- ข้อมูลปีเก่ายังอยู่ครบ
- เมื่อสิ้นปีการศึกษา ระบบจะขึ้นเป็นปีใหม่ให้เอง

**ค่า `EMAIL_DOMAIN` คืออะไร**
ระบบแปลงชื่อผู้ใช้เป็นอีเมลภายใน เช่น `somjai` → `somjai@school.local` เพราะ Firebase ต้องใช้รูปแบบอีเมล
ตั้งครั้งเดียวก่อนเริ่มใช้งาน และไม่ควรเปลี่ยนภายหลัง

**ค่าใช้จ่าย**
แพ็กเกจฟรี (Firebase Spark + Vercel Hobby) เพียงพอสำหรับโรงเรียนทั่วไป
